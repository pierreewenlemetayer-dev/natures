# Arbitrages grammaticaux validés — lot 04

Date : 31 octobre 2026. Décisions expressément validées par l'utilisateur.

| Mot | Classes grammaticales retenues |
|---|---|
| plus | adverbe ; nom |
| moins | adverbe ; nom |
| mal | adverbe ; nom |
| juste | adjectif ; adverbe ; **nom** |
| fort | adjectif ; adverbe ; nom |
| ensemble | adverbe ; nom |

**Point important :** pour « juste », l'utilisateur a explicitement choisi d'ajouter le **nom** à la proposition initiale. Ne pas omettre cette classe lors de la fusion du corpus.

Ces décisions sont documentées uniquement dans la branche `developpement-corpus-lexique4`. Elles n'entraînent aucune modification du corpus utilisé par la version publique sur `main`.
